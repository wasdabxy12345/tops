s3: You are building the menu listing page for a food delivery app. All available dishes are stored in a JavaScript array. You need to display every dish name in the console and, separately, count how many dishes are marked as vegetarian.
Question: Which loop construct would you use for each task — displaying all dishes and counting vegetarian ones — and why? Explain the practical difference between for-of and forEach in this context, and when you would prefer one over the other.
  • for-of for displaying all dishes: because it provides a straightforward way to access each dish object directly
  • forEach for counting vegetarian dishes: because it is useful when we want to perform an action on every array element

practical difference between both:

  1. for-of supports break, contiune, and return but forEach doesn't
  2. for-of works with async and await but forEach doesn't
  3. for-of works with any non-primitive data type whereas forEach only works for array

prefer one over another:

  • for-of: when we need to conditionally break out of iteration, working asynchronously, or iterate over non-arrays
  • forEach: when we want to chain it directly after other array methods, or when we want to perform the same operation on all the items in an array
